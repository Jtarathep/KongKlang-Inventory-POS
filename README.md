# KongKlang - Inventory & POS Management System

KongKlang is an inventory and point-of-sale management
system developed as an academic project.

## Features

- Product management
- Category management
- Inventory management
- Stock movement
- Purchase management
- Sales management
- POS system
- Reporting

## Technologies

- Java
- Spring Boot
- React
- MySQL
- REST API
- JWT

## System Architecture

Frontend:
React

Backend:
Spring Boot

Database:
MySQL

## Project Purpose

The system was developed to help small retail stores
manage products, inventory, purchases, and sales
more efficiently.
